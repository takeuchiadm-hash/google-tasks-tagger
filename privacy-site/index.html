TaskTags Privacy Policy

Last updated: 2026-06-03

TaskTags is a Chrome Extension that helps users view and organize their Google Tasks with tags.

Data Access

TaskTags requests access to Google Tasks data using the Google Tasks API.

The extension reads:

  • Google Task lists
  • Task titles
  • Task notes
  • Task due dates
  • Task completion status

TaskTags stores tag metadata locally in the user's Chrome browser using chrome.storage.local.

Data Use

TaskTags uses Google Tasks data only to display tasks and allow the user to organize them with tags.

TaskTags does not sell user data.

TaskTags does not use Google Tasks data for advertising.

TaskTags does not transfer Google Tasks data to third parties.

TaskTags does not use Google Tasks data to train AI models.

Data Storage

Task data remains in Google Tasks.

Tag metadata is stored locally in the user's Chrome browser. It is not sent to an external server.

Google API Limited Use

TaskTags' use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
